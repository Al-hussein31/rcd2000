file names of eleven characters (name plus extensions). Once the names are specified. the program
assigns the input device number 3 to the input file name and output device number 4 to the output file
name. This program segment is taken from program SLAB and the reader is advised to study this in its
full context.The first executable line opens the terminal (console) as a file and the second opens the printer as a file.

output. PRN and LPTI, LPT2 are for parallel port printers (the most common) while COMI, COM2,
